# 项目简介

## 核心功能
- 歌曲元数据信息分析
- 构建歌曲物品相似度矩阵
- 计算用户兴趣相似度
- 选择与用户兴趣相似的候选用户
- 基于协同过滤算法生成个性化推荐列表
- 可视化推荐列表展示

## 适用场景
- 音乐平台个性化推荐
- 用户兴趣分析
- 音乐推荐系统开发

## 技术特点
- Python编程语言实现
- 协同过滤算法推荐机制
- 系统稳定运行，代码可运行
